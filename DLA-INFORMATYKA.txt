🚀 INSTALACJA KROK PO KROKU:
═══════════════════════════════════════════════════════════════

KROK 1: Skopiuj wszystkie pliki na serwer
-----------------------------------------------
Rozpakuj archiwum do katalogu aplikacji (np. /home/user/emkametal/)

KROK 2: Zainstaluj zależności Node.js
-----------------------------------------------
cd /home/user/emkametal/
npm install --production

KROK 3: Skonfiguruj plik send-email.php
-----------------------------------------------
Edytuj: public/send-email.php

Linia 16 - ZMIEŃ EMAIL:
$recipient_email = 'kontakt@emkametal.pl'; // ← WPISZ WŁAŚCIWY

Linia 20-24 - DODAJ DOMENĘ:
$allowed_origins = [
    'http://localhost:3000',
    'https://emkametal.pl',        // ← TWOJA DOMENA
    'https://www.emkametal.pl'     // ← TWOJA DOMENA + WWW
];

KROK 4: Ustaw uprawnienia
-----------------------------------------------
chmod 644 public/send-email.php
chown www-data:www-data public/send-email.php (lub użytkownik serwera)

KROK 5: Uruchom aplikację Next.js
-----------------------------------------------
# Sposób 1: Bezpośrednio (dla testów)
npm start
# Aplikacja uruchomi się na porcie 3000

# Sposób 2: Z PM2 (dla produkcji - POLECANE)
npm install -g pm2
pm2 start npm --name "emkametal" -- start
pm2 save
pm2 startup

KROK 6: Konfiguracja Nginx/Apache
-----------------------------------------------

NGINX (przykładowa konfiguracja):
-----------------------------------
server {
    listen 80;
    server_name emkametal.pl www.emkametal.pl;
    
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    location /send-email.php {
        root /home/user/emkametal/public;
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}

APACHE (przykładowa konfiguracja z .htaccess):
------------------------------------------------
Utwórz plik .htaccess w public/:

RewriteEngine On
RewriteBase /

# Obsługa PHP
<FilesMatch "\.php$">
    SetHandler application/x-httpd-php
</FilesMatch>

# Proxy do Next.js
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_URI} !^/send-email\.php
RewriteRule ^(.*)$ http://localhost:3000/$1 [P,L]

⚠️ ROZWIĄZYWANIE PROBLEMÓW:
═══════════════════════════════════════════════════════════════

Problem: Email nie jest wysyłany
Rozwiązanie:
- Sprawdź czy funkcja mail() działa: php -r "mail('test@test.pl', 'Test', 'Test');"
- Sprawdź logi PHP: tail -f /var/log/php-fpm/error.log
- Jeśli mail() nie działa, skonfiguruj Postfix/Sendmail lub użyj PHPMailer

Problem: CORS error w konsoli
Rozwiązanie:
- Dodaj domenę do $allowed_origins w send-email.php
- Sprawdź nagłówki: curl -H "Origin: https://emkametal.pl" -I https://emkametal.pl/send-email.php

Problem: 404 Not Found dla send-email.php
Rozwiązanie:
- Sprawdź ścieżkę: ls -la /home/user/emkametal/public/send-email.php
- Sprawdź uprawnienia: chmod 644 send-email.php
- Sprawdź konfigurację Nginx/Apache

Problem: Next.js nie startuje
Rozwiązanie:
- Sprawdź logi: npm start 2>&1 | tee error.log
- Sprawdź czy Node.js jest zainstalowany: node -v (min. v18)
- Sprawdź czy port 3000 jest wolny: lsof -i :3000
